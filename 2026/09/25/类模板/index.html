类模板

类模板

类模板与函数模板类似：

  • 类模板支持模板参数默认值
  • 类模板内的自身模板名等价于改模板被调用时所生成的实例
  • 类模板不具备模板参数实参的推导机制，不具备默认模板参数只能一一赋值

普通类中也可以有成员函数模，可以在类内当场实现也可以在类外单独实现

类模板的成员函数还可以有额外的模板参数，如：

C++中友元函数模板与类模板的任何实例都是该类的友元，可以访问类中私有成员
class citizen
{
int id;
double money;
// 友元类
template
friend class FBI_agent;
// 友元函数
template
friend T duty(citizen &);
public:
citizen(int id):id(id){}
};

类模板静态成员变量的实现与类模板实现放在同一可见范围内。通常，将静态成员变量的实现写在类模板实现之后，由于是类模板的成员，其实现也必须写成模板

编译器就可针对类模板的静态成员变量做特殊处理：

  • 在目标文件中写入类模板实例中静态成员变量的初始值。
  • 在汇编代码中为该变量临时分配一个内存地址，且在目标文件中标记该地址所关联的变量名及链接属性等，以便在随后由链接器修改地址，以正确实现多个类模板实例共享同一内存地址。
  • 按照类静态成员的概念，所有类实例都应该共享同一套静态成员存储空间。在链接时，链接器将随机选择一个目标中的空间作为最终存储空间，从而使不同目标文件中的多个等价模板实例共享同一套静态成员存储空间
