模板特例

模板特例

在进行模板特化（特例）时，匹配式写在模板类名之后，用尖括号 < > 括起。编写特化匹配式需要遵循以下几条规则：

  • 位置与符号：匹配式写在模板类名之后，用尖括号括起。
  • 参数数量：匹配式用逗号分隔的项目列表，项目数必须与通例（主模板）模板参数总数一致。
  • 参数类型：匹配式中各项类型必须与通例对应模板参数类型一致。
  • 参数值：匹配式项目可以是具体的模板参数值，也可以是特例自己声明的模板参数。
  • 修饰符：当匹配式项目是类型模板参数时，与函数变量类似，模板参数也可以用 *、&、const 及 volatile 修饰。

多种特例写法

特例匹配规则

C++模板特化的匹配遵循“最特殊化优先”的原则，编译器会将用户提供的实参按“完全特化 > 部分特化 > 主模板（通例）”的优先级进行模式匹配。编写特化时，匹配式必须与主模板保持参数数量一致，但允许将部分参数固定为具体类型、值或添加 const、*、& 等修饰；特化版本自身的模板参数列表（template<…>）只需声明匹配模式中剩余的“未知量”，且其参数命名与主模板完全无关（独立作用域）。当多个特化版本同时匹配一组实参时，编译器会尝试寻找约束最严苛的那一个，若无法区分谁更特殊，就会引发二义性（Ambiguity）编译错误。

#include
// #1 泛型模板函数：接受任意类型的参数 T
template
void func(T v) {std::cout << “#1: “ << v << std::endl;}
// #2 模板特化：针对 float 类型的显式特化版本
template<>
void func(float v) {std::cout << “#2: “ << v << std::endl;}
// #3 普通函数重载：针对 float 类型的非模板重载版本
void func(float v) {std::cout << “#3: “ << v << std::endl;}
// #4 普通函数：名为 func2，接受 float 类型参数
void func2(float v) {std::cout << “#4: “ << v << std::endl;}
int main()
{
func2(1); // 输出 “#4: 1” (int 隐式转换为 float，调用 #4)
func(1); // 输出 “#1: 1” (模板推导 T=int，调用泛型模板 #1)
func(1.); // 输出 “#1: 1” (模板推导 T=double，调用泛型模板 #1)
func(1.f); // 输出 “#3: 1” (非模板函数优先于模板特化，调用 #3)
func<>(1.f); // 输出 “#2: 1” (显式指定模板参数，强制调用模板特化 #2)
}
